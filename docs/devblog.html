How work moves forward

  1. Set the target. Decide what should feel better in play.
  2. Build a prototype. Keep experiments separate from the public build.
  3. Test in the game. Check visuals, sound and gameplay together.
  4. Refine and review. Fix what falls short; a successful export is not the finish line.
  5. Accept and ship. Mark work done after developer acceptance, then package verified changes.
