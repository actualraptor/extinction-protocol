# Extinction Protocol 0.14.3 — Boss Build Fixes

T-rex and Triceratops retain their rebuilt models, grounded pursuit and directional attacks. Meteor remains in development, with further updates planned.

This build restores missing runtime dependencies, includes the boss attack artwork inside the game package, and keeps experimental beam audio out of ordinary gameplay.

Windows performance checks include both dinosaur bosses and a 400-enemy stress scenario. Existing progress is retained. Linux is not included in this release.
