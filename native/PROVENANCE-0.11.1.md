# 0.11.1 assets

Kael ground slam uses original AI-generated artwork, directed from the existing Kael character design. Two source sheets and twelve cleaned transparent frames are retained in assets/kael-slam-0111. The six poses per skin were authored with common scale and foot anchors. Normal stone club and Halloween pumpkin club are both included. No third-party game art was copied.

Cards reuse the project's original slate artwork and procedural carved borders. Patch notes reuse the original Hollow Harvest cover and existing game icons. Cinzel and Source Sans 3 font license files accompany the packages.

All 18 user-provided Kael voice originals and their runtime copies were renamed to kael_event_number.mp3, numbered from 1 within each event. SHA-256 checks confirm unchanged audio; the rename manifest preserves the original names. Godot import metadata was regenerated and all event banks were tested.
