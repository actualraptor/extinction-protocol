# 0.11.3 provenance

Starter audio consists of nine original procedurally synthesized WAVs: three variations each for Voss's revolver, Vesper's Stormbinder and lightning chain impacts. No sampled or downloaded material was used. Generator: tools/build_starter_audio_0113.py. Original audio remains unchanged; hash-verified backups and restore instructions are retained outside the exported project in backups/audio-0113. Setting NEW_STARTER_AUDIO=false restores the original banks.

Emission points are manually annotated on the existing original survivor attack frames. Boss pursuit and crit effects reuse the project's existing artwork. Patch notes reuse the original Hollow Harvest cover and game icons. Cinzel and Source Sans 3 licenses accompany release archives. Original artwork and development use AI assistance, directed and playtested by the project owner.
