# Card artwork provenance

Six full card backgrounds were generated with the built-in ImageGen tool, using player-supplied PNG and Grok JPEG examples as visual references. Each asset was generated separately and copied into assets/cards-0115. The references informed materials and composition. Text, item icons, reward numbers and controls remain live Godot UI.

Generation prompts are recorded in assets/cards-0115/prompts.json. Original generated files remain in the Codex generated_images folder. No external gameplay text from the reference examples was imported.

Common: fossil stone and bone. Uncommon: emerald roots. Rare: silver-blue crystal. Epic: thorned bronze/violet. Legendary: gold/fire. Artifact: prismatic cosmic crystal.
