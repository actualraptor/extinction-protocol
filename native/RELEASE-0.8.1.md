# 0.8.1 — UI finish

- Upgrade cards now reserve space inside the illustrated corners and borders.
- Smaller icons, wrapped titles and revised text spacing keep descriptions and purchase buttons inside their cards.
- Added serif headings and warm ivory/gold text to match the fossil-and-metal artwork.
- Replaced plain menu buttons with textured stone-and-brass controls, including hover, pressed, disabled and keyboard focus states.
- Archive purchases wrap longer descriptions and fit text to the available button area.
- Discoveries use matching textured rows, wrapped descriptions and styled unlock buttons.
- Fixed the Discovery Archive's outdated two-max-weapons evolution instruction.
- Preserved 0.8 gameplay rules and existing saves.

Validation: 769 native layout/text checks passed across all weapon/passive/augment cards and Archive, Discoveries and survivor buttons. Reviewed captures at 1024x640, 1280x800 and 3440x1440. Existing Archive navigation, purchase/reload and HUD tests also passed. Windows export smoke-tested separately.
